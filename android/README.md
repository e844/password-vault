# כספת סיסמאות – גרסה 0.1 (גרסת בדיקה)

אפליקציית אנדרואיד לניהול סיסמאות. הממשק בעברית, מימין לשמאל, בעיצוב Material You.
האפליקציה עובדת בלי אינטרנט ויוצרת כספת עם **נתוני דוגמה בלבד**.

## מה יש בגרסה הזו
- יצירת כספת עם סיסמת מאסטר, ופתיחה שלה. סיסמת המאסטר לא נשמרת בשום מקום.
- הוספה, עריכה, מחיקה וחיפוש של רשומות (שם, שם משתמש, סיסמה, כתובת והערות).
- מחולל סיסמאות: אורך 8 עד 64, בחירת סוגי תווים, אפשרות בלי תווים דומים ומד חוזק.
- נעילה אוטומטית אחרי 2 דקות בלי מגע במסך, או 30 שניות אחרי מעבר לרקע. יש גם כפתור נעילה ידני.
- אחרי 5 ניסיונות שגויים יש השהיה שהולכת וגדלה.
- העתקה ללוח: הלוח מתנקה אחרי 30 שניות ובכל נעילה, והתוכן מסומן כרגיש.
- חסימת צילומי מסך והסתרת התוכן במסך "אפליקציות אחרונות".
- Material You: באנדרואיד 12 ומעלה הצבעים נלקחים מהטפט, ומצב כהה עובר אוטומטית.

**לא כלול** (נשאר לגרסה הבאה): סנכרון ענן ומילוי אוטומטי.

## אבטחה בקצרה
- ההצפנה משתמשת רק בספריית ההצפנה הסטנדרטית של Java ואנדרואיד (JCA). אין בקוד מימוש הצפנה עצמי.
  - **PBKDF2-HMAC-SHA256** עם 600,000 חזרות ומלח אקראי גוזר מפתח מסיסמת המאסטר.
  - **AES-256-GCM** מצפין את הכספת ומאמת אותה. כך מתגלים גם סיסמה שגויה וגם קובץ ששונה.
- הבדיקה שהסיסמה נכונה נעשית לפי הצלחת הפענוח. אין קובץ עם הסיסמה או עם hash שלה.
- המפתח קיים רק בזיכרון ונמחק בנעילה.
- אין הרשאת אינטרנט ואין גיבוי לענן (`allowBackup=false`).
- אין בקוד כתיבה ללוג או הדפסה. בדיקה אוטומטית סורקת את הקוד ומוודאת את זה.

מגבלות ידועות: שדות טקסט באנדרואיד שומרים את הסיסמה כמחרוזת בזיכרון בזמן ההקלדה, ואי אפשר למחוק אותה ידנית. ההשהיה אחרי ניסיונות שגויים מתאפסת כשמפעילים את האפליקציה מחדש.

## איך בונים APK ב-Windows (פעם ראשונה, בערך 30–45 דקות, רובן הורדות)

### 1. התקנת Android Studio
1. היכנס ל- https://developer.android.com/studio ולחץ **Download Android Studio**.
2. הרץ את קובץ ההתקנה והשאר את כל ברירות המחדל (Next, Next, Install).
3. בהפעלה הראשונה בחר **Standard** ואשר את הרישיונות (**Accept**). Android Studio יוריד את ה-Android SDK. זה לוקח זמן.

> Android Studio כולל בתוכו את Java, אז אין צורך להתקין אותה בנפרד.

### 2. פתיחת הפרויקט
1. חלץ את קובץ ה-ZIP לתיקייה, למשל `C:\Projects\PasswordVault`.
   כדאי נתיב באנגלית בלבד, בלי עברית ובלי רווחים.
2. ב-Android Studio: **File → Open**, בחר את התיקייה `PasswordVault` ולחץ **OK**.
   אם תופיע שאלה **Trust Project**, לחץ **Trust Project**.
3. המתן עד שהסנכרון בתחתית המסך יסתיים (**Gradle sync**). בפעם הראשונה זה יכול לקחת 5–15 דקות.
4. אם מופיעה הצעה לשדרג גרסה (**Upgrade Assistant / AGP upgrade**), לחץ **Remind me later** או **Don't ask again**. הפרויקט מוגדר לגרסאות שהוא נבנה איתן.

### 3. הרצת הבדיקות (רשות)
בתחתית המסך פתח את **Terminal** והקלד:
```
.\gradlew.bat test
```
בסוף אמור להופיע `BUILD SUCCESSFUL`.

### 4. בניית ה-APK
בתפריט: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
בסיום תופיע הודעה בפינה עם קישור **locate**. ה-APK נמצא כאן:
```
PasswordVault\app\build\outputs\apk\debug\app-debug.apk
```
אפשר גם להריץ ב-Terminal `.\gradlew.bat assembleDebug`.

**אם משהו נכשל:** העתק את הודעת השגיאה מחלון **Build** (בתחתית המסך) ושלח לי אותה. נמשיך משם.

## התקנה בטלפון
1. העבר את `app-debug.apk` לטלפון: בכבל USB, בגוגל דרייב או במייל לעצמך.
2. בטלפון, פתח את הקובץ (למשל מאפליקציית **Files** ← **הורדות**).
3. אנדרואיד יבקש אישור להתקין מהמקור הזה. לחץ **הגדרות** והפעל **אישור ממקור זה**, ואז חזור ולחץ **התקנה**.
4. אם Play Protect מזהיר על אפליקציה לא מוכרת, לחץ **פרטים נוספים ← התקנה בכל זאת**. זה צפוי ב-APK לבדיקה שלא פורסם בחנות.
5. פתח את **כספת סיסמאות**, בחר סיסמת מאסטר, ותיווצר כספת עם 5 רשומות דוגמה.

דרישות: אנדרואיד 8.0 ומעלה. הצבעים הדינמיים פועלים מאנדרואיד 12.

```
    VaultStore.kt      קובץ הכספת המוצפן, יצירה, פתיחה, שמירה ונעילה
    VaultCodec.kt      המרת הרשומות לבייטים
    VaultEntry.kt      רשומה, חיפוש, הוספה, עדכון ומחיקה
    PasswordGenerator.kt  מחולל וחוזק סיסמה
    AutoLockPolicy.kt  נעילה אוטומטית והשהיה אחרי ניסיונות שגויים
    SampleData.kt      נתוני דוגמה
  ui/              מסכים (Jetpack Compose + Material 3), ViewModel ועיצוב
  MainActivity.kt
app/src/test/      31 בדיקות יחידה
```
