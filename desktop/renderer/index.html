    בדיקת עדכונים

    אחרי ההורדה: סגור את התוכנה, חלץ את קובץ ה-ZIP החדש והפעל את PasswordVault.exe מהתיקייה החדשה. הכספת שלך נשמרת בנפרד ולא תימחק. מומלץ ליצור קודם גיבוי מוצפן.

    הבדיקה מתחברת ל-GitHub רק כשלוחצים על הכפתור. שום מידע מהכספת לא נשלח.

    מילוי אוטומטי בדפדפן

    תוסף קטן ל-Chrome / Edge / Brave ממלא שם משתמש וסיסמה באתרים. הוא מדבר רק עם התוכנה הזו במחשב – בלי אינטרנט – וממלא רק באתר שהכתובת שלו תואמת לרשומה.

    1. לחץ פתח את תיקיית התוסף (נפתחת תיקייה בשם browser-extension).
    2. בדפדפן פתח את chrome://extensions (ב-Edge: edge://extensions). אפשר ללחוץ העתק כתובת ולהדביק בשורת הכתובת.
    3. הפעל את Developer mode / מצב מפתח (מתג בפינה).
    4. לחץ Load unpacked / טען פריט לא ארוז ובחר את תיקיית browser-extension.
    5. זהו. כשתיכנס לשדה התחברות באתר, תופיע רשימה קטנה מתחת לשדה. הכספת צריכה להיות פתוחה בתוכנה.
