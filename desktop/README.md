# כספת סיסמאות – גרסת Windows

אפליקציית Electron. הממשק בעברית, מימין לשמאל, בעיצוב Material You. הצבעים נלקחים מצבע ההדגשה של Windows, ומצב כהה עובר אוטומטית. האפליקציה עובדת בלי אינטרנט, וכל בקשת רשת נחסמת.

- **הצפנה:** מודול ההצפנה המובנה של Node (OpenSSL). PBKDF2-HMAC-SHA256 עם 600,000 חזרות, ו-AES-256-GCM. אין מימוש הצפנה עצמי.
- **סיסמת מאסטר:** לא נשמרת. המפתח נמצא רק בתהליך הראשי, והממשק לא מקבל את הסיסמאות ברשימה.
- **נעילה אוטומטית:** אחרי 2 דקות בלי פעילות, 30 שניות אחרי מזעור, ומיד בנעילת מסך או במעבר לשינה.
- **לוח העתקה וצילומי מסך:** הלוח מתנקה אחרי 30 שניות ובכל נעילה. צילום מסך של החלון חסום.
- **מיקום הכספת:** `%APPDATA%\PasswordVault\vault.bin`

**בדיקות:**
- `npm test` – בדיקות יחידה
- `npm run test:e2e` – בדיקת קצה לקצה (דורשת מסך)
